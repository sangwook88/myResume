# 기능: 포인트목록조회

*한 프로젝트에 속한 published 포폴 포인트들을 요약 목록으로 돌려준다. 프로젝트인덱스의 포인트 목록 + 포인트상세의 "같은 프로젝트 다른 포인트"에 쓰인다. be/project가 index 조립 시에도 호출(be/project→be/point).*

## 다루는 데이터
- [데이터.md](데이터.md)#포폴포인트-frontmatter (status=`published`만)

## 입력
- `project` slug.

## 처리
- 해당 `project`의 `status: published` 포인트만 추린다.
  - 정렬은 v1에서 강제 요구 없음 — 구현 기본(임의) 정렬 허용.

## 출력·변경
- 포인트 요약 목록: `id`, `title`, `tags`. (읽기)

## 예외·경계
- 존재하지 않는 `project`: 빈 목록 반환.
- published 포인트 0개: 빈 목록(안내 표현은 fe/browse).
