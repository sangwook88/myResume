# 요소: 프로젝트-인덱스

*한 프로젝트의 인덱스 문서(index.md)를 렌더한다. 채용자가 "이 프로젝트 뭐예요?"에 먼저 보는 카탈로그.*

## 진입·트리거
- 랜딩에서 프로젝트 카드 선택.

## 로드하는 값 (입력)
- 보장: `project` slug.
- 읽는 값: 해당 프로젝트의 index 데이터 — 한 줄 요약 · 역할/기간/팀 규모 · 기술 스택 · 아키텍처 개요 · 핵심 성과 · 포폴 포인트 목록(published만).
  - (근거: [포폴-목차-설계.md §4](../../../포폴-목차-설계.md))

## 호출하는 기능
*be/point 미명세(FE-first). 제공해야 할 호출 후보.*
- 프로젝트 인덱스 데이터 조회(`project` 기준) → [be/point](../../../be/point/) *[입력 필요: 기능 문서 링크]*
- 해당 프로젝트의 published 포인트 목록 조회 → [be/point](../../../be/point/) *[입력 필요: 기능 문서 링크]*

## 분기·다음 전이
- **포인트 목록 항목 선택** → 포폴-포인트-상세 (포인트 `id` 전달)
- **전역 FAB 클릭** → fe/chat 진입

## 내보내는 값 (출력)
- 포인트상세로: 포인트 `id`, 소속 `project`

## 예외·실패 처리
- 존재하지 않는/비공개 `project`: *[입력 필요: 404·접근 처리]*
- 프로젝트는 있으나 published 포인트 0개: *[입력 필요: 빈 목록 안내]*

## 화면·연출 (V)
- index.md 6요소 렌더(요약·역할·스택·아키텍처·성과·포인트 목록).
- *[입력 필요: 아키텍처 개요 다이어그램 노출 방식]*
- 우하단 전역 FAB 상시 표시.
