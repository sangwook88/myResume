# 기능: 챗봇컨텍스트조회 *(v4 신설)*

*be/chat 코퍼스 조립 전용. published 포인트(단건 `id` 또는 전체)를 **visible 본문 + invidence(detail·code) 합집합**으로 돌려주는 유일한 접근자 — 공개 조회(단건·목록)와 물리적으로 분리된 경로라 invidence가 공개 응답으로 새지 않는다(be/chat→be/point).*

## 다루는 데이터
- [데이터.md](데이터.md)#포폴포인트-frontmatter
- [데이터.md](데이터.md)#포폴포인트-본문--9섹션-staradr
- [데이터.md](데이터.md)#evidence-포인트-종속--근거-필수
- [데이터.md](데이터.md)#invidence-evidence-종속--숨은-층--챗봇-전용

## 입력
- 포인트 `id`(단건 맥락) 또는 없음(published 전체 — load-all 코퍼스용).

## 처리
- `status: published`만.
- 공개 9섹션·Evidence(kind·label·url)에 더해 **각 Evidence의 invidence(detail·code)를 함께** 싣는다.

## 출력·변경
- 하이브리드 컨텍스트(frontmatter + 9섹션 + Evidence + 각 Evidence의 invidence). 읽기 전용, 상태 변경 없음.
- be/chat이 이 위에서 인용 토큰(`[[E##]]`)·프롬프트 캐싱 코퍼스를 조립.

## 예외·경계
- invidence 없는 Evidence: 해당 필드 생략(visible만).
- 없는/`draft` id: 빈 컨텍스트 반환 — 근거 없음 거부는 be/chat.
