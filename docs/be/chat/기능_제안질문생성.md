# 기능: 제안질문생성

*진입 맥락이 특정 포인트일 때, 그 포인트에 관한 제안 질문을 만들어 돌려준다. 무맥락 기본 질문은 FE 정적 자원이라 여기서 만들지 않는다.*

## 다루는 데이터
- (참조) [be/point](../point/데이터.md) 해당 포인트 본문(published)

## 입력
- 포인트 `id`(맥락).

## 처리
- 해당 포인트 본문을 근거로 관련 질문 **3개**를 생성.
  - 핵심 섹션(제목·요약·문제·결정과 근거) 기반. 세부 프롬프트는 구현 시.

## 출력·변경
- 제안 질문 문자열 목록. (상태 변경 없음 — 읽기)

## 예외·경계
- 포인트가 없거나 published 아님: 빈 목록(FE가 정적 기본 질문으로 폴백).
