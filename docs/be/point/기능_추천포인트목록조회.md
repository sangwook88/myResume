# 기능: 추천포인트목록조회

*랜딩 상단에 노출할 "추천 포폴 포인트" 집합을 published 중에서 골라 요약 목록으로 돌려준다.*

## 다루는 데이터
- [데이터.md](데이터.md)#포폴포인트-frontmatter (status=`published`만)

## 입력
- 없음(공개 진입).

## 처리
- `status: published`인 포인트 중 **`featured` 태그가 달린 포인트를 우선**, 동점(또는 featured 부족 시 보충)은 **`updated` 최신순**으로 상위 **3개**를 추천 집합으로 선정.

## 출력·변경
- 포인트 요약 카드 목록: `id`, `title`, `tags`, 소속 `project`. (상태 변경 없음 — 읽기)

## 예외·경계
- published 0개: 빈 목록 반환(빈 상태 *표현*은 fe/browse).
- 데이터 로드 실패: v1 특별 요구 없음 — 구현 표준 에러 처리.
