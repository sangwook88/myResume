# 요소: 질문-응답

*질문을 전송하면 답변을 표시하고, 답변 끝에 근거(커밋/PR/Swagger) 링크 목록을 NotebookLM식으로 노출한다. 멀티턴으로 이어진다. 이 도메인의 핵심.*

## 진입·트리거
- 챗봇-열림에서 질문 전송 또는 제안 질문 클릭. 또는 본 노드에서 이어 질문.

## 로드하는 값 (입력)
- 질문 텍스트 + 진입 맥락(포인트 `id` 또는 무맥락) + 누적 대화 이력.
- 답변 + 인용 근거(Evidence 링크) — be/chat이 published 포인트를 load-all해 생성.

## 호출하는 기능
*be/chat 미명세(FE-first). 제공해야 할 호출 후보.*
- 질문 → 답변 생성(published load-all + 근거 인용) → [be/chat](../../../be/chat/) *[입력 필요: 기능 문서 링크]*
- 대화 턴 영속 저장 → [be/chat](../../../be/chat/) *[입력 필요: 기능 문서 링크]*

## 분기·다음 전이
- **이어 질문(입력 전송)** → 질문-응답 (재진입, 이력 누적)
- **답변 내 근거 링크 클릭** → 외부 근거 URL 새 탭 이탈
- **닫기** → fe/browse 복귀 (이력은 영속)

## 내보내는 값 (출력)
- 외부근거로: Evidence 외부 URL
- (재진입) 다음 턴 질문 + 누적 이력
- 영속 저장: 이번 턴(질문·답변·근거)

## 예외·실패 처리
- 답을 코퍼스에서 찾지 못함(근거 없음): *[입력 필요: "근거 없어 답할 수 없음" 류 처리 — 환각 방지 차별점]*.
- 응답 생성 실패/타임아웃: *[입력 필요: 재시도·에러 표시]*.
- 답변은 있으나 인용 근거가 비는 경우: *[입력 필요: 근거 없는 답 노출 정책]*.

## 화면·연출 (V)
- 말풍선형 멀티턴. 답변 본문 + 하단 "근거" 링크 목록(외부 새 탭).
- 응답 생성 중 로딩 표시. 메시지 영역 `role="log"`+`aria-live="polite"`.
- *[입력 필요: 스트리밍 표시 여부]*.
