# 기능: 발행코드추출 *(v4 신설)*

*draft→published 발행 시 **1회**, 각 Evidence의 커밋/PR ref에서 코드를 뽑아 그 Evidence의 `invidence.code`에 심는다. git-읽기는 **발행 플로우의 얇은 유틸**(런타임 아님) — 서빙 시 git 접근 없음, 로컬 git 사용.*

## 다루는 데이터
- [데이터.md](데이터.md)#evidence-포인트-종속--근거-필수 (kind·url에서 ref 도출)
- [데이터.md](데이터.md)#invidence-evidence-종속--숨은-층--챗봇-전용 (`code` 채움 대상)
- [데이터.md](데이터.md)#포폴포인트-frontmatter (`commits` git range — ref 후보)

## 입력
- 발행 대상 포인트 1개 + 그 Evidence 목록.

## 처리
- kind가 **commit·pr**인 Evidence마다 ref에서 코드 추출:
  - **ref 출처**(확정): Evidence `url`의 커밋 해시.
  - **추출 단위**(확정): **변경 hunk만**(`git show`류 diff hunk).
  - **크기 상한 초과 시**(확정): 앞부분만 남기고 자름 + `…(잘림)` 표시(chatbot 맥락은 일부라도 확보, 코퍼스 폭주 방지). 상한 값 자체는 구현 튜닝.
- 결과를 **사이드카 파일** `wiki/<project>/<id>.code.md`의 `code`에 기록(확정).

## 출력·변경
- 각 대상 Evidence의 `invidence.code` 채워짐(발행 1회). 이후 [챗봇컨텍스트조회](기능_챗봇컨텍스트조회.md)가 읽음.
- 발행 게이트(Evidence≥1 + 핵심 섹션)는 불변 — 게이트 통과 후 부가 추출.

## 예외·경계
- git 실패(미설치·저장소 아님)는 삼켜 code 없이 발행 진행(발행 자체는 성공, Evidence 링크는 유효).
- ref 해석 실패(없는 커밋·얕은 클론·detached)(확정): code 비우고 발행 진행(발행 막지 않음 — git 미설치 처리와 동일, Evidence 링크는 유효).
- 재발행(확정): 기존 `invidence.code`를 덮어씀 — 재발행마다 Evidence 커밋 기준으로 재추출해 사이드카 교체(항상 최신 diff, 버전 누적 안 함).
