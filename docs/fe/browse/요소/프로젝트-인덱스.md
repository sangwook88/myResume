# 요소: 프로젝트-인덱스

*한 프로젝트의 인덱스 문서(index.md)를 렌더한다. 채용자가 "이 프로젝트 뭐예요?"에 먼저 보는 카탈로그. 아키텍처는 압축 도식(SVG) 우선.*

## 진입·트리거
- 랜딩에서 프로젝트 카드 선택.

## 로드하는 값 (입력)
- 보장: `project` slug.
- 읽는 값: 해당 프로젝트의 index 데이터 — 한 줄 요약 · 역할/기간/팀 규모 · 기술 스택 · 아키텍처 개요 · 핵심 성과 · 포폴 포인트 목록(published만).
  - **v4**: 아키텍처 압축 도식 애셋 참조 `architectureDiagram`(있으면 SVG 경로, 없으면 null)도 함께 받는다.
  - (근거: [포폴-목차-설계.md §4](../../../포폴-목차-설계.md))

## 호출하는 기능
- 프로젝트 인덱스 데이터 조회(`project` 기준) + published 포인트 목록 조립 → [be/project 기능_프로젝트인덱스조회](../../../be/project/기능_프로젝트인덱스조회.md) (포인트 목록은 be/project가 be/point에서 조립).

## 분기·다음 전이
- **포인트 목록 항목 선택** → 포폴-포인트-상세 (포인트 `id` 전달)
- **전역 FAB 클릭** → fe/chat 진입

## 내보내는 값 (출력)
- 포인트상세로: 포인트 `id`, 소속 `project`

## 예외·실패 처리
- 존재하지 않는/노출 불가 `project`: 랜딩으로 리다이렉트.
- 프로젝트는 있으나 published 포인트 0개: 표지는 그대로 노출하되 포인트 목록 슬롯을 표시하지 않는다.

## 화면·연출 (V)
- index.md 6요소 렌더(요약·역할·스택·아키텍처·성과·포인트 목록).
- 아키텍처 개요는 텍스트/마크다운으로 노출.
- **v4 — 압축 도식 임베드**: `architectureDiagram`이 있으면 그 SVG를 아키텍처 개요에 인라인 임베드 — 압축 도식이 먼저, 텍스트 서술이 보조. `null`이면 텍스트만(하위호환). 임베드 방식·다크모드 대비·배치 미세값은 구현.
- 우하단 전역 FAB 상시 표시.
