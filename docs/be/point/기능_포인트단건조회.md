# 기능: 포인트단건조회

*포폴 포인트 1개를 id로 찾아 9섹션 본문 + frontmatter + Evidence를 통째로 돌려준다. 포인트상세 화면의 본체.*

## 다루는 데이터
- [데이터.md](데이터.md)#포폴포인트-frontmatter
- [데이터.md](데이터.md)#포폴포인트-본문--9섹션-staradr
- [데이터.md](데이터.md)#evidence-포인트-종속--근거-필수

## 입력
- 포인트 `id` (+ 참고용 소속 `project`).

## 처리
- `id`로 단건 조회, **`status: published`만** 노출.

## 출력·변경
- 포인트 전체: frontmatter + 9섹션 본문 + Evidence 목록(kind·label·url). (읽기)

## 예외·경계
- 없는/비공개 `id`: 랜딩으로 리다이렉트.
- Evidence 결손: 발행 게이트가 Evidence ≥1을 강제하므로 published에는 결손이 없다(별도 표기 불필요).
- 부분 렌더: 핵심 섹션(1·3·5·9)은 발행 게이트로 보장됨. 선택 섹션(배경·실행·결과·회고·옵션표)이 비면 **해당 섹션을 생략하고 렌더**(빈 섹션 미표시).
