# 요소: 랜딩

*포트폴리오 메인 페이지. 상단에 추천 포폴 포인트, 하단에 프로젝트 목록을 나열한다.*

## 진입·트리거
- 루트 URL 진입(공개 페이지, 인증 없음).

## 로드하는 값 (입력)
- 받는 값 없음(진입점).
- 읽는 값: `status: published` 포인트 중 **추천 포인트 집합**(`featured` 태그 우선 + 동점 `updated` 최신순 상위 **3**) + **프로젝트 목록**(모두 노출, published 포인트 0개는 후순위).

## 호출하는 기능
- 추천 published 포인트 목록 조회 → [be/point 기능_추천포인트목록조회](../../../be/point/기능_추천포인트목록조회.md)
- 프로젝트 카탈로그 목록 조회 → [be/project 기능_프로젝트목록조회](../../../be/project/기능_프로젝트목록조회.md)

## 분기·다음 전이
- **프로젝트 카드 선택** → 프로젝트인덱스 (`project` slug 전달)
- **추천 포인트 선택** → 포폴-포인트-상세 (포인트 `id`(+`project`) 전달)
- **전역 FAB 클릭** → fe/chat 진입 (전역 연출, 플로우.md 참조)

## 내보내는 값 (출력)
- 프로젝트인덱스로: `project` slug
- 포인트상세로: 포인트 `id`, 소속 `project`

## 예외·실패 처리
- published 포인트 0개 / 프로젝트 0개(빈 상태): 해당 영역에 빈 상태 안내 표시(카피는 구현).
- 데이터 로드 실패: 구현 표준 에러 표시.

## 화면·연출 (V)
- 상단: 추천 포인트 카드 영역 / 하단: 프로젝트 카드 영역.
- 디자인 템플릿(기본 비주얼) v1 포함. 톤·레이아웃 상세는 구현.
- 우하단 전역 FAB 상시 표시(전역 연출).
