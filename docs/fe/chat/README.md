## 책임지지 않는 것
- **챗봇 응답 생성·load-all·근거 인용·맥락 제안 질문 생성** — be/chat. 여기선 호출(링크)만.
- **세션 대화 이력 저장/로드** — be/chat(서버 세션, 만료형). UI는 `session_id`로 호출·표시만.
- **진입 버튼(전역 FAB) 자체** — fe/browse가 소유(진입구). 여기선 *열린 뒤*를 다룬다.
- **포폴 포인트 데이터** — be/point.

> 대화 이력은 v1에서 **세션 쿠키(`session_id`) + 서버 세션 저장, TTL 1일 만료형**으로 이어간다(만료 후 자동 삭제 → 오래된 이력 재등장 방지). 무맥락 기본 제안 질문은 FE 정적 자원.
