# fe/chat 일지

## 현재 상태 요약
plan-fe 신규 골격 생성 완료. 패널 상태 전이(챗봇열림 → 질문응답 멀티턴) 확정. 제안 질문+입력창 초기 상태, 답변 끝 근거 링크 목록, 재방문 이력 영속, FAB 진입 시 보던 포인트 맥락 전달. 값 슬롯([입력 필요]) 다수 — 이력 영속 키(무인증), 제안 질문 출처, 근거 없음 처리, be/chat 기능 링크 등. be/chat은 FE-first로 아직 미명세.

## 이력
### 2026-06-27 — fe/chat 플로우·UI 확정
- **결정:** 초기 상태=제안 질문 버튼+입력창. 근거=답변 끝 출처 링크 목록(NotebookLM식, 외부 새 탭). 대화 이력=재방문해도 영속. FAB로 열 때 보던 포인트를 맥락으로 전달.
- **왜:** 채용자 가이드(제안 질문)·근거기반 신뢰(근거 링크)·맥락 질문(보던 포인트) 모두 제품 차별점과 직결(리서치 근거). 영속 이력으로 재방문 연속성.
- **영향:** be/chat에 응답 생성(load-all+근거)·이력 영속(무인증 식별)·제안 질문 제공이 요구됨 → plan-be 입력. fe/browse FAB 컨텍스트 슬롯 닫힘(보던 포인트 전달).
