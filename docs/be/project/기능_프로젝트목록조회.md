# 기능: 프로젝트목록조회

*랜딩 하단 카탈로그에 노출할 프로젝트 목록을 요약 형태로 돌려준다.*

## 다루는 데이터
- [데이터.md](데이터.md)#프로젝트index-표지

## 입력
- 없음(공개 진입).

## 처리
- 모든 프로젝트를 노출 대상으로 한다. published 포인트 0개인 프로젝트는 **후순위로 배치**.
  - 같은 순위군 내 정렬은 v1에서 강제 요구 없음 — 구현 기본(임의) 정렬 허용.

## 출력·변경
- 프로젝트 요약 카드 목록: `slug`, `summary`(+ 표시용 메타). (읽기)

## 예외·경계
- 프로젝트 0개: 빈 목록(빈 상태 표현은 fe/browse).
- 데이터 로드 실패: v1 특별 요구 없음 — 구현 표준 에러 처리.
