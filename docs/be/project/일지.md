# be/project 일지

## 현재 상태 요약
decompose에서 be/point로부터 SRP 분리되어 신설(plan-be) + 사람 값 확정 완료. 데이터(프로젝트 index 표지 §4의 1~5) + 기능 2개(프로젝트목록조회·프로젝트인덱스조회). 포인트 목록은 저장 않고 be/point에서 파생 조립(§7.3). 비즈니스 값 전부 충족 — 정렬=구현 기본, 0-포인트 프로젝트=노출하되 후순위+포인트슬롯 숨김, 아키텍처=텍스트/마크다운, 없는 slug=랜딩 리다이렉트, 포맷=케밥 slug·`YYYY.MM–`. 남은 슬롯은 패턴(TS/DM, arch)뿐.

**v4 확장(plan-be):** 긴 architecture 텍스트를 보완하는 **압축 아키텍처 도식(typst→SVG)** 신설 — 표지에 optional `architectureDiagram`(SVG 애셋 참조) 필드 + 소스=typst 사이드카(사람 저작). 기능 1개 추가(도식컴파일=빌드 시 1회 typst→SVG 컴파일, invidence.code와 같은 빌드타임 유틸·서빙 아님). 인덱스조회가 architectureDiagram 함께 반환, fe/browse가 임베드. distill로 v4 도식 문서 가지치기 완료(결정이력 흡수·중복 통합). **남은 슬롯 사람 확정(plan-be):** 사이드카=`wiki/<project>/architecture.typ`→`architecture.svg` / 컴파일 실패=발행 스크립트가 사람에게 프롬프트(비우고 진행/중단, 기본=비우고 진행). **잔여 슬롯 0** → arch로 진행 가능.
