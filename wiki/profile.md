8개월간의 앱 개발 실무를 통해 사용자 중심의 서비스 **기획부터 배포까지** 아우르는 역량을 다져왔습니다.
이 과정에서 얻은 가장 확고한 개발 철학은 **'기술 스택과 자동화 도구는 결국 개발자가 완벽히 통제하고 책임질 수 있어야 한다'**는 것입니다.

저는 하네스 엔지니어링과 AI(AX)를 **적극적으로 활용합니다.** 반복 작업을 걷어내고 설계에 집중할 시간을 벌어주는 강력한 지렛대이기 때문입니다. 다만 **활용과 의존은 다릅니다.** 도구가 만들어낸 결과를 이해하지 못한 채 쌓아 올리면 그것은 곧 인지 부채가 됩니다. 프로덕션에서 치명적인 버그가 발생해 30분 안에 핫픽스를 배포해야 하는 상황에서, 내부 구조를 한 번에 진단하고 책임질 사람이 없다면 아무리 화려한 오케스트레이션도 무용지물이기 때문입니다.

그래서 저는 도구를 쓰되 **통제권은 사람이 쥐도록 설계하는 쪽**을 택해왔습니다. AI에게 맡길 범위와 사람이 확정해야 할 판단을 구분하고, 그 경계를 규약과 코드로 강제하는 방식입니다. LLM의 컨텍스트가 포화되거나 최적의 결과물이 나오지 않는 한계 상황에서도, 결국 문제를 해결하고 품질을 책임지는 것은 엔지니어의 몫이기 때문입니다.

트렌드나 도구를 좇기보다 **코드의 내부 아키텍처를 명확히 이해하고 근본적인 개발 방법론을 유연하게 적용하는 것**이 더 중요하다고 생각합니다. 어떠한 기술 스택이 주어지든, 철저한 구조적 이해를 바탕으로 위기 상황에서도 즉각 진단하고 책임질 수 있는 견고한 서비스를 구축하겠습니다.

### 경력

- **양봉 ㈜** (2026.02 ~ 재직중) · 앱개발 — OpenAI API 기반 RAG 챗봇, Supabase(PostgreSQL) 서버리스 아키텍처 설계 및 백엔드 자동화, FCM 푸시, 실시간 채팅 시스템 설계, 결제 시스템 연동
- **모바일앱개발협동조합** (2025.11 ~ 2025.12) · Flutter 팀장 · SI — Flutter 앱 풀스택 개발, 부동산 데이터 기반 RAG 챗봇, React 웹사이트 UI 설계
- **경기대학교(수원) 컴퓨터공학** (2024.03 ~ 2026.02, 편입/졸업예정)

### 개인 개발

원스토어에 1인 개발로 앱 2종을 출시했습니다 — **고미로**(AI 미식 여행 플랫폼), **Lit Mate**(챗봇 기반 논문 작성 어시스턴트).
졸업 작품으로 **약사친구**(LLM 일반의약품 추천)를 개발했고, 2024년 경기대학교 논문경진대회(한국정보기술학회)에 입상했습니다.
