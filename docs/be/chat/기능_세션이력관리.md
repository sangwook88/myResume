# 기능: 세션이력관리

*`session_id` 기준으로 대화 이력을 로드·저장하고 TTL로 만료시킨다. 세션 동안 멀티턴을 이어주고, 만료되면 자동 삭제해 오래된 이력이 되살아나지 않게 한다.*

## 다루는 데이터
- [데이터.md](데이터.md)#대화세션 · [데이터.md](데이터.md)#turn-세션-종속

## 입력
- 로드: `session_id`.
- 저장: `session_id` + append할 Turn(질문 또는 답변+근거).

## 처리
- **로드**: `session_id`로 세션을 찾아 만료 안 됐으면 turns 반환. 없거나 만료면 빈 이력.
- **저장**: Turn을 세션 turns에 append(질문·답변·근거 전부 보관). 세션 없으면 생성(createdAt·expiresAt 설정).
- **만료**: `expiresAt = 마지막 활동 + TTL(1일)` — **sliding**(로드·저장 등 활동마다 갱신). 만료 세션은 조회 시 빈 이력 취급 + 삭제.
  - 만료 삭제는 스토어 레벨 TTL(쓰기마다 갱신)로 처리 — 정확한 스토어는 arch.

## 출력·변경
- 로드: turns(또는 빈 이력).
- 저장: 세션 turns 갱신(+ 신규 세션 생성).

## 예외·경계
- 만료·없는 `session_id` 로드: 빈 이력 반환(FE가 빈 대화로 시작).
- 저장 실패: 에러 반환(FE 표현).
