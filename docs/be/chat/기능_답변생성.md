# 기능: 답변생성

*질문 + 누적 이력 + 진입 맥락을 받아, published 하이브리드 코퍼스(visible+invidence)를 load-all해 근거와 함께 답변을 스트리밍으로 생성한다. 이 도메인의 핵심. RAG 아님(v1=전부 로드).*

## 다루는 데이터
- [데이터.md](데이터.md)#대화세션 (누적 turns 읽기)
- (참조) [be/point 챗봇컨텍스트조회](../point/기능_챗봇컨텍스트조회.md) — published 포인트의 **visible 본문 + Evidence + invidence(디테일·코드) 합집합**을 읽는 챗봇 전용 접근자.
- (참조) [be/project](../project/데이터.md) 프로젝트 표지

## 입력
- 질문 텍스트 · 진입 맥락(포인트 `id` 또는 무맥락) · 누적 대화 이력.

## 처리
- **published 코퍼스 전체를 컨텍스트에 로드**(load-all): 각 published 포인트의 visible 9섹션 본문 + Evidence + invidence(detail=사람 디테일·일화, code=발행 시 추출한 변경 hunk) + 프로젝트 표지. v1은 코퍼스가 컨텍스트 예산 내라고 가정 — 초과하면 RAG(v3) 도입 신호(로드맵 정합).
- **invidence는 각 Evidence 토큰(`[[E##]]`) 밑에** 붙는다(디테일·코드가 그 근거에 종속). 인용 계약 불변 — 토큰→Citation 매핑 그대로이며, invidence 자체는 인용 대상이 아니라 답변 맥락이다.
- invidence는 이 챗봇 코퍼스에만 존재 — 화면(fe/browse)이 렌더하는 공개 조회 함수엔 절대 안 섞인다([be/point 공개/비공개 분리](../point/데이터.md)).
- `mode=hr`이면 invidence.code가 코퍼스에 있어도 **출력**에서 코드·파일명 노출 금지(코퍼스=맥락, tone=출력 수위 — 상충 아님).
- 진입 맥락(포인트 `id`)은 코퍼스를 재배치하지 않고, 가변 꼬리에 짧은 포인터("가장 관련 있는 포인트=`id`")로만 표현한다.
- 답변을 **스트리밍**(토큰 점진)으로 생성하고, 근거가 된 Evidence를 인용으로 첨부.
- **근거 없으면 답하지 않는다**: 코퍼스에서 인용할 근거를 못 찾으면 일반지식으로 추측하지 않고 "근거가 없어 답할 수 없음"류로 응답(환각 방지 차별점).
- 응답 타임아웃 **30초** — 초과 시 실패로 처리.

### 프롬프트 캐싱 (프리픽스 안정성)
*요건만 고정 — cache_control 배치·beta 헤더·langchain 배선은 [arch](../../arch/ARCHITECTURE.md) 몫.*
- **프리픽스 순서**: ① 고정 지시문(규칙·거부·구분자) → ② **안정 코퍼스**(published+invidence를 **고정 정준 순서**로; 진입 맥락으로 재배치하지 않는다) → **캐시 대상 프리픽스 경계** → ③ 가변 꼬리(진입 맥락 포인터·tone·질문). `tone`(technical↔hr)은 반드시 캐시 브레이크포인트 **뒤**(가변 꼬리)에 둔다.
- **캐시 실측**: 스트리밍 usage(`cache_read_input_tokens`·`cache_creation_input_tokens`)를 관측·로깅해 히트를 검증한다.
- **TTL**: **1h**. 포폴 챗봇은 방문 간격이 길어 기본 5분 TTL이면 방문자마다 프리픽스 캐시가 만료·재생성된다 → 1h로 유지해 미스·비용을 줄인다. (1h TTL용 beta 헤더·cache_control 배선은 arch.)
- **경계**: 캐싱은 load-all(기본 경로) 대상. RAG(top-K, build_corpus_rag)는 프리픽스가 본질적으로 불안정해 범위 밖(RAG 자체는 2026-07-13 피벗으로 **안 함/YAGNI** — 코퍼스 ~50K 초과 시에만 재검토).

## 출력·변경
- 답변 본문(스트리밍) + 인용 근거 목록(kind·label·url).
- assistant Turn을 세션에 append(→ [기능_세션이력관리](기능_세션이력관리.md)).

## 예외·경계
- published 0개(빈 코퍼스): 근거 없음과 동일 — 답할 내용이 없다는 안내(카피는 구현).
- 생성 실패·30초 타임아웃: 에러 반환(FE가 재시도 표현).
