# 요소: 챗봇-열림

*챗봇 패널이 열린 초기 상태. 제안 질문 버튼과 입력창을 함께 띄운다. 재방문이면 기존 대화 이력을 먼저 보여준다.*

## 진입·트리거
- fe/browse 전역 FAB 클릭(랜딩·인덱스·포인트상세 어디서나).

## 로드하는 값 (입력)
- 진입 맥락: 현재 보던 포인트 `id`(포인트 상세에서 열린 경우) 또는 무맥락.
- 기존 대화 이력(재방문 시) — *[입력 필요: 이력 영속 키]*.
- 제안 질문 목록 — *[입력 필요: 출처(정적 목록 / 맥락 기반 생성) · 개수]*. 맥락 있으면 그 포인트 관련 질문 우선할지: *[입력 필요]*.

## 호출하는 기능
*be/chat 미명세(FE-first). 제공해야 할 호출 후보.*
- 대화 이력 로드(영속 키 기준) → [be/chat](../../../be/chat/) *[입력 필요: 기능 문서 링크]*
- 제안 질문 목록 제공 → *[입력 필요: be/chat인지 정적 자원인지 결정]*

## 분기·다음 전이
- **입력창에 질문 전송** → 질문-응답 (질문 텍스트 + 맥락 전달)
- **제안 질문 버튼 클릭** → 질문-응답 (그 질문을 전송)
- **닫기** → fe/browse 복귀

## 내보내는 값 (출력)
- 질문-응답으로: 질문 텍스트, 진입 맥락, (있으면) 누적 이력

## 예외·실패 처리
- 이력 로드 실패 / 식별 불가(첫 방문): 빈 대화로 시작 — *[입력 필요: 첫 방문 안내 문구]*.
- published 포인트 0개라 답할 코퍼스 없음: *[입력 필요: 안내]*.

## 화면·연출 (V)
- 상단 이력 영역 + 하단 입력창 + 제안 질문 칩.
- 열릴 때 입력 필드로 포커스. Esc 닫기.
- *[입력 필요: 패널 크기·위치, 모바일 전체화면 여부]*.
