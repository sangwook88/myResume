# 요소: 랜딩

*포트폴리오 메인 페이지. 상단에 추천 포폴 포인트, 하단에 프로젝트 목록을 나열한다.*

## 진입·트리거
- 루트 URL 진입(공개 페이지, 인증 없음).

## 로드하는 값 (입력)
- 받는 값 없음(진입점).
- 읽는 값: `status: published` 포인트 중 **추천 포인트 집합** + **프로젝트 목록**.
  - *[입력 필요: 추천 포인트 선정 기준 — 수동 지정 / 최신순 / 태그·핵심성과 기준 등]*
  - *[입력 필요: 추천 포인트 노출 개수]*
  - *[입력 필요: 프로젝트 목록 정렬 기준(최신순/수동)]*

## 호출하는 기능
*BE 기능 링크 — be/point 미명세(FE-first). 아래는 be/point이 제공해야 할 호출 후보.*
- 추천 published 포인트 목록 조회 → [be/point](../../../be/point/) *[입력 필요: 기능 문서 링크]*
- 프로젝트(인덱스) 목록 조회 → [be/point](../../../be/point/) *[입력 필요: 기능 문서 링크]*

## 분기·다음 전이
- **프로젝트 카드 선택** → 프로젝트인덱스 (`project` slug 전달)
- **추천 포인트 선택** → 포폴-포인트-상세 (포인트 `id`(+`project`) 전달)
- **전역 FAB 클릭** → fe/chat 진입 (전역 연출, 플로우.md 참조)

## 내보내는 값 (출력)
- 프로젝트인덱스로: `project` slug
- 포인트상세로: 포인트 `id`, 소속 `project`

## 예외·실패 처리
- published 포인트 0개 / 프로젝트 0개(빈 상태): *[입력 필요: 빈 상태 안내 문구·화면]*
- 추천 포인트는 있으나 프로젝트가 없는 경우 등 부분 빈 상태: *[입력 필요]*
- 데이터 로드 실패: *[입력 필요: 에러 표시 방식]*

## 화면·연출 (V)
- 상단: 추천 포인트 카드 영역 / 하단: 프로젝트 카드 영역.
- 디자인 템플릿(기본 비주얼)은 v1 포함 — *[입력 필요: 템플릿 톤·레이아웃 상세]*.
- 우하단 전역 FAB 상시 표시(전역 연출).
