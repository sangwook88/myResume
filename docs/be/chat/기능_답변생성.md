# 기능: 답변생성

*질문 + 누적 이력 + 진입 맥락을 받아, published 코퍼스를 load-all해 근거와 함께 답변을 스트리밍으로 생성한다. 이 도메인의 핵심. RAG 아님(v1=전부 로드).*

## 다루는 데이터
- [데이터.md](데이터.md)#대화세션 (누적 turns 읽기)
- (참조) [be/point](../point/데이터.md) published 포폴포인트 본문 + Evidence
- (참조) [be/project](../project/데이터.md) 프로젝트 표지

## 입력
- 질문 텍스트 · 진입 맥락(포인트 `id` 또는 무맥락) · 누적 대화 이력.

## 처리
- **published 코퍼스 전체를 컨텍스트에 로드**(load-all): published 포인트 9섹션 본문·Evidence + 프로젝트 표지. v1은 코퍼스가 컨텍스트 예산 내라고 가정 — 초과하면 그때 RAG(v3) 도입 신호(로드맵 정합).
- 맥락(포인트 `id`)이 있으면 그 포인트를 우선 컨텍스트로.
- 답변을 **스트리밍**(토큰 점진)으로 생성하고, 근거가 된 Evidence를 인용으로 첨부.
- **근거 없으면 답하지 않는다**: 코퍼스에서 인용할 근거를 못 찾으면 일반지식으로 추측하지 않고 "근거가 없어 답할 수 없음"류로 응답(환각 방지 차별점).
- 응답 타임아웃 **30초** — 초과 시 실패로 처리.

## 출력·변경
- 답변 본문(스트리밍) + 인용 근거 목록(kind·label·url).
- assistant Turn을 세션에 append(→ [기능_세션이력관리](기능_세션이력관리.md)).

## 예외·경계
- published 0개(빈 코퍼스): 근거 없음과 동일 — 답할 내용이 없다는 안내(카피는 구현).
- 생성 실패·30초 타임아웃: 에러 반환(FE가 재시도 표현).
