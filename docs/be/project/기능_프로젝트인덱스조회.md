# 기능: 프로젝트인덱스조회

*한 프로젝트의 표지 데이터(요약·역할/기간/팀·스택·아키텍처·핵심성과)를 돌려주고, 그 프로젝트의 published 포인트 목록을 be/point에서 조립해 함께 반환한다. 프로젝트인덱스 화면의 본체.*

## 다루는 데이터
- [데이터.md](데이터.md)#프로젝트index-표지
- (파생) [be/point 포인트목록조회](../point/기능_포인트목록조회.md) — `slug` 기준 published 포인트 목록

## 입력
- `project` slug.

## 처리
- `slug`로 표지 단건 조회.
- 같은 `slug`의 published 포인트 목록을 be/point에서 스캔해 조립(목차-설계 §7.3).

## 출력·변경
- 표지 6요소(summary·role/period/teamSize·techStack·architecture·highlights) + 포인트 요약 목록(id·title·tags). (읽기)

## 예외·경계
- 존재하지 않는/노출 불가 `slug`: 랜딩으로 리다이렉트.
- 표지는 있으나 published 포인트 0개: 표지(요약·역할·스택·아키텍처·성과)는 그대로 노출하되 **포인트 목록 슬롯은 표시하지 않는다**(빈 슬롯 숨김).
