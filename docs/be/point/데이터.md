# be/point 데이터 (M)

*이 도메인이 소유한 마스터 데이터. 파일 단위 = `wiki/<project>/<id>.md` 1개 = 포폴 포인트 1개. 근거: [포폴-목차-설계.md §5·§7](../../포폴-목차-설계.md).*

## 포폴포인트 (frontmatter)
*문서 상단 YAML. 기계가 읽는 메타데이터(목차-설계 §7.1).*

| 필드 | 타입 | 의미 | 값·범위 |
|---|---|---|---|
| id | string(slug) | 파일명·링크용 식별자 | 케밥 영문 slug (예 `payment-distributed-lock`) |
| title | string | 포인트 제목 | 자유 문자열, v1 강제 길이 제한 없음 |
| project | string(slug) | 소속 프로젝트 slug (→ be/project) | 존재하는 케밥 slug |
| status | enum | 발행 상태 | `draft` \| `published` (아래 enum) |
| tags | string[] | 검색·필터·인덱스 그룹핑 | 자유 문자열 배열, v1 고정 집합 없음. 예약값 `featured`(추천 우선 표시) |
| commits | string | 근거 커밋 범위 | git range `a1b2c3d..e4f5g6h` |
| updated | date | 마지막 수정일 | ISO `YYYY-MM-DD` (예 `2026-06-07`) |

## 포폴포인트 (본문 — 제목·요약 + 핵심 4 + 심화 3 + Evidence)
*핵심 4는 포인트 페이지에 노출한다. 심화 3은 페이지에서 접고 be/chat의 심화 답변 맥락으로 사용한다.*

| 구분 | 섹션 | 내용 |
|---|---|---|
| 요약 | 제목·요약 | 한 줄 요약 |
| 핵심 | 문제 | 풀어야 했던 문제·제약 |
| 핵심 | 고려한 옵션 | 고정 컬럼 표(옵션·장점·단점·비용/리스크·채택) — 목차-설계 §7.4 |
| 핵심 | 결정과 근거 | 무엇을 골랐고 왜 + 기각 이유 |
| 핵심 | 결과 | 정량+정성 임팩트 |
| 심화 | 배경 | 어느 지점에서 생긴 일 |
| 심화 | 실행 | 실제 구현·변경 (근거 링크) |
| 심화 | 회고 | 배운 점·한계 |
| 근거 | Evidence | 근거 링크 목록(아래 Evidence) |

요약과 핵심·심화의 산문 섹션 본문에는 `![](<url>)` 형식의 인라인 이미지를 넣을 수 있다.

## Evidence (포인트 종속 · 근거 필수)
*포인트당 1개 이상 필수 — 비면 published 무효(roadmap: "evidence 비면 무효"). 클릭-검증용 외부 링크.*

| 필드 | 타입 | 의미 | 값·범위 |
|---|---|---|---|
| kind | enum | 근거 종류 | 아래 enum 참조 (5종) |
| label | string | 표시 라벨 | 예: 커밋 메시지·PR 제목·엔드포인트 |
| url | string(URL) | 외부 원본 링크 (새 탭 이탈) | 유효 URL |

## enum
- **status**
  - `draft` — 초안. 챗봇 인용·노출 안 함(또는 "미확인 초안").
  - `published` — 발행됨. 채용자 화면·챗봇에 노출.
  - 전이: **별도 발행 명령/스크립트**로 draft→published 전환. 발행 게이트 검증 조건: **Evidence ≥1개** + **제목·요약 / 문제 / 결정과 근거가 채워짐**. 미충족이면 발행 거부.
- **evidence.kind**
  - `commit` — 커밋 링크
  - `pr` — Pull Request 링크
  - `swagger` — API 스펙(Swagger) 링크
  - `file` — 코드/파일 경로
  - `link` — 일반 URL

## Invidence (Evidence 종속 · 숨은 층 — 챗봇 전용) *(v4 신설)*
*각 Evidence 밑 0~1개의 비공개 부가 정보. repository는 invidence까지 raw로 파싱하되 **공개 조회(단건·목록)·fe/browse 렌더에서 제외** — be/chat 전용 접근자([기능_챗봇컨텍스트조회](기능_챗봇컨텍스트조회.md), visible+invidence 합집합)만 노출.*

| 필드 | 타입 | 의미 | 출처(누가 채우나) | 값·범위 |
|---|---|---|---|---|
| detail | string? | 그 근거에 얽힌 사람의 디테일·일화(왜 이렇게 했나·당시 상황·곁가지 결정) | 사람 — pofol 인터뷰 저작 | 자유 텍스트, 명시 상한 없음 |
| code | string? | 그 근거가 커밋/PR이면 발행 시 추출한 코드(**변경 hunk만**) | 기계 — 발행 플로우([기능_발행코드추출](기능_발행코드추출.md)) | 상한 초과 시 앞부분 자름 + `…(잘림)` 표시(상한 값은 구현 튜닝) |

- **추출 대상 kind**(확정): **commit·pr만**(ref = Evidence `url`의 커밋 해시). swagger·file·link는 code 추출 안 함.
- **저장 위치**(확정): `detail`(사람 글)=포인트 문서 안 숨은 섹션 — Evidence 토큰별 `## 챗봇전용 [[E##]]` 블록. `code`(기계 diff)=사이드카 파일 `wiki/<project>/<id>.code.md`(본문 .md 깨끗·git 노이즈 격리).
- **발행 게이트 영향**: 없음 — invidence 유무는 게이트에 영향 없음(invidence 없어도 발행 가능, Evidence≥1 규칙 불변).
