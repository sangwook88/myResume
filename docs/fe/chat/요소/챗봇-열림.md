# 요소: 챗봇-열림

*챗봇 패널이 열린 초기 상태. 제안 질문 버튼과 입력창을 함께 띄운다. 재방문이면 기존 대화 이력을 먼저 보여준다.*

## 진입·트리거
- fe/browse 전역 FAB 클릭(랜딩·인덱스·포인트상세 어디서나).

## 로드하는 값 (입력)
- 진입 맥락: 현재 보던 포인트 `id`(포인트 상세에서 열린 경우) 또는 무맥락.
- 세션 대화 이력 — 세션 쿠키 `session_id`로 be/chat 서버 세션에서 로드(TTL 1일). 만료·첫 방문이면 없음.
- 제안 질문 목록 — **하이브리드**: 무맥락이면 정적 기본 질문, 포인트 맥락이면 그 포인트 관련 질문 우선. 3~4개.

## 호출하는 기능
*be/chat 미명세(FE-first). 제공해야 할 호출 후보.*
- 세션 대화 이력 로드(`session_id` 기준) → [be/chat](../../../be/chat/).
- 맥락(포인트 `id`) 기반 제안 질문 생성 → [be/chat](../../../be/chat/). 무맥락 기본 질문은 FE 정적 자원.

## 분기·다음 전이
- **입력창에 질문 전송** → 질문-응답 (질문 텍스트 + 맥락 전달)
- **제안 질문 버튼 클릭** → 질문-응답 (그 질문을 전송)
- **닫기** → fe/browse 복귀

## 내보내는 값 (출력)
- 질문-응답으로: 질문 텍스트, 진입 맥락, (있으면) 누적 이력

## 예외·실패 처리
- 첫 방문·세션 만료(TTL 1일 경과)·이력 로드 실패: 빈 대화로 시작하고 제안 질문 표시(안내 문구는 구현 카피).
- published 포인트 0개라 답할 코퍼스 없음: 빈 상태 안내 표시(카피는 구현).

## 화면·연출 (V)
- 상단 이력 영역 + 하단 입력창 + 제안 질문 칩.
- 열릴 때 입력 필드로 포커스. Esc 닫기.
- 데스크톱=우하단 패널, 모바일=전체화면.
