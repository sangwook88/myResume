# be/chat 데이터 (M)

*이 도메인이 소유한 마스터 데이터 = 대화 세션. 챗봇 코퍼스(published 포인트·프로젝트 표지)는 소유하지 않고 be/point·be/project에서 읽는다.*

## 대화세션
*익명 방문자의 대화 1묶음. `session_id`로 식별(인증 없음), TTL 만료형.*

| 필드 | 타입 | 의미 | 값·범위 |
|---|---|---|---|
| session_id | string | 세션 식별자(FE 세션 쿠키가 전달) | 서버 발급 불투명 문자열 |
| context | string(nullable) | 진입 맥락 = 보던 포인트 `id` 또는 무맥락(null) | be/point `id` 또는 null |
| turns | Turn[] | 대화 턴 목록(시간순) | 아래 Turn |
| createdAt | datetime | 세션 생성 시각 | ISO datetime |
| expiresAt | datetime | 만료 시각 | 마지막 활동 + **TTL 1일** (sliding, 활동마다 갱신) |

## Turn (세션 종속)
*한 번의 질문-답변. assistant 턴은 인용 근거를 함께 보관.*

| 필드 | 타입 | 의미 | 값·범위 |
|---|---|---|---|
| role | enum | 발화 주체 | `user` \| `assistant` |
| text | string | 질문(user) 또는 답변 본문(assistant) | — |
| citations | Citation[] | assistant 턴의 인용 근거 | user 턴은 빈 배열 |

## Citation (Turn 종속)
*답변이 인용한 근거 = be/point Evidence를 그대로 참조.*

| 필드 | 타입 | 의미 | 값·범위 |
|---|---|---|---|
| kind | enum | 근거 종류 | be/point evidence.kind 재사용(commit·pr·swagger·file·link) |
| label | string | 표시 라벨 | — |
| url | string(URL) | 외부 원본 링크 | 유효 URL |

## enum
- **role**
  - `user` — 방문자 질문
  - `assistant` — 챗봇 답변
- **citation.kind** — [be/point 데이터.md#enum](../point/데이터.md) evidence.kind와 동일(단일 소유는 be/point, 여기선 참조).
